Featured Project · AI / Finance
StockMind AI — Market Intelligence Platform

An AI-native stock analysis platform that democratises institutional-grade market intelligence for retail investors. Built around a proprietary Self-Comparison Engine that benchmarks a stock against its own historical performance at any checkpoint — enabling regime change detection and signal quality assessment without relying on external benchmarks or market indices.

Rather than relying on any single model, StockMind fuses five specialised ML approaches into a single unified Conviction Score (0–100). This gives investors one interpretable, real-time signal that captures price momentum, volatility risk, market sentiment, regime context, and cyclical patterns simultaneously.

PythonLSTMGARCH FinBERTRandom ForestFourier Analysis NLPTime Series
Five-Model ML Ensemble
  • LSTM — deep recurrent sequence model for multi-step price trajectory forecasting across historical regimes
  • GARCH — volatility modelling for risk-adjusted signal weighting and tail-risk estimation
  • FinBERT — transformer-based NLP for sentiment scoring on financial news, earnings calls, and filings
  • Random Forest — robust market regime classifier (bull / bear / ranging) using technical and macro features
  • Fourier Analysis — cyclical pattern and seasonality detection across multiple frequency bands
Institutional-Grade Signals

  • Short Squeeze scoring using float, short interest, cost-to-borrow, and days-to-cover metrics

Machine Learning · Web Application
Crime Type & Occurrence Prediction System

A full-stack machine learning application designed to assist law enforcement agencies and urban planners in understanding crime patterns across time and geography. The system classifies incoming incident reports by crime type and predicts future occurrence hotspots using historical spatial-temporal data.

The project spans a complete ML pipeline — from raw data ingestion and cleaning through feature extraction, model training, evaluation, and a browser-based interface for querying predictions in real time. It demonstrates how classical ML methods, properly engineered, can deliver interpretable and actionable results in high-stakes public-safety domains.

PythonMySQLScikit-learn Bernoulli Naïve BayesHTML / CSSJavaScript
Technical Approach
  • Ingested and cleaned multi-year urban crime datasets, handling missing values, inconsistent geocoding, and label noise across thousands of records
  • Engineered temporal features (hour-of-day, day-of-week, seasonal flags) and spatial features (district codes, proximity scores) to improve downstream classification accuracy
  • Applied Bernoulli Naïve Bayes for efficient categorical classification, carefully evaluating attribute independence assumptions across the full crime label taxonomy
  • Stored structured crime records in a normalised MySQL schema with indexing optimised for real-time prediction lookup queries
  • Built a JavaScript-based browser interface that allows analysts to query predictions by location, time window, and crime category without touching the underlying model
Outcome
  • Delivered accurate crime category classification with measurable F1 improvement over frequency-based baselines across held-out test sets
  • Demonstrated how spatial-temporal feature engineering significantly outperforms raw feature input for geographically distributed classification tasks
